# Reshis Airlines Frontend

## Стек
- Языки: JavaScript, CSS, HTML
- Зависимости: Node.js 22, Vite 8.3.8, Charts.js 4.6.1, flatpickr 4.6.13
- Хостинг: [Netlify](https://www.netlify.com/)
- Ассистенты: Claude, ChatGPT

## Описание
Фронтенд для турнира "Решись!", направления "Технологии", блока "Разработка". Взаимодействует с [бэкендом](https://github.com/goset33/Airlines-Backend). Реализованный функционал:
- Регистрация и авторизация через Яндекс ID.
- Запрос и получение данных о спросе по рейсам, датам, цене.
- Построение графика на основе этих данных.

## О работе с бэкендом
Клиент напрямую не общается с бэкендом -- он делает запросы на прокси фронтенда `/api/*`, а прокси уже перенаправляет запросы на реальный бэкенд. Это нужно для того, чтобы не использовать куки с `SameSite=None`, которые блокируют некоторые браузеры.

## Как запустить локально
Нужен установленный Node.js версии минимум 22.12.0 и локальный бэкенд. 
1. `git clone https://github.com/goset33/Airlines-Frontend.git && cd Airlines-Frontend`
2. Скопируйте файл `.env.example` и переименуйте в `.env.local`. Укажите адрес бэкенда в `API_PROXY_TARGET`. 
3. `npm install`
4. `npm run dev`
